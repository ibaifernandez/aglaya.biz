# ROI Diagnostic — lead-magnet micro-project

> **Status:** concept / documentation-first (NOT built). Created 2026-06-15.
> Micro-project inside aglaya.biz. Born from a Socratic design debate (founder-led).

## One-line

Turn the `/roi-audit` qualifier from a robotic 3-question form into a **gamified,
Typeform-style interactive diagnostic (a free lead magnet)** whose payoff is a
**personalized, branded mini business-case** that brands AGLAYA into the
prospect's memory and pulls them up a value ladder toward the real product: **a
bespoke Stack build (five/six figures).**

## The chain of insight (how we got here)

1. The `%`-automated slider is unanswerable — nobody can self-rate "65% automated". False precision the engine throws away anyway (it only buckets into 3 bands).
2. So: start from the end. **What's the real sale?** Not the ROI Audit — the **Stack** (a multi-tens-of-thousands development). The ROI Audit is the *paid door* to it; the diagnostic is the *free door* to the audit.
3. The Stack is **not a catalog of products** — it's the **capacity to assemble a bespoke operating system** from sub-developments. Web/Pulse/Outreach/Kanban are **receipts** (proof we build production-grade automation across 4 fronts), not the menu. The menu is "whatever bleeds you".
4. So the form should **diagnose → prescribe**, not audit. "What bleeds you? → Do you already have a tool for it? → How big is it?" Each pain maps to a buildable solution. That *sells*.
5. The form is therefore a **lead magnet**: gamified flow → email-gate → personalized "panfleto" that reflects their pain back with a number + shows the system that stops it + proof.
6. **The engine already exists, in spirit:** legal-reg-tech turns a passive web scan into a deterministic report. With *first-person form answers* (richer input) we can generate something far stronger — reusing its architecture (deterministic rules + contracts + optional LLM polish + evidence tracing).

## Hard guardrail (non-negotiable)

AGLAYA's brand is **uncomfortable honesty**. We may convey *readiness* ("we've
built this 4 times, we assemble yours") — we may **not** fake that the Stack is
pre-built. The "sensación de que sí" is earned with proof + speed, never with a
lie. A diagnostic that over-promises betrays the one thing the brand sells.
