# 02 — Problem taxonomy ("what bleeds you")

The diagnostic's central question is **"¿qué te sangra más ahora mismo?"** with a
broad, recognizable menu. Below: the universe of automatable pains, grouped by
**business function** (NOT by AGLAYA product — the Stack is bespoke; we don't
force pains into 4 boxes). Each is something a prospect recognizes in 1 second.

## The menu (40+, by function)

**Marketing**
1. Reportes de marketing armados a mano cada mes.
2. Sin atribución: no sé qué canal/campaña trae dinero.
3. Publicar en redes una a una, manual.
4. Emails enviados a mano, sin segmentar.
5. Contenido reescrito desde cero cada vez.

**Ventas**
6. Prospección manual (buscar / copiar / pegar / enviar).
7. Seguimiento de leads a destiempo o inexistente.
8. Calificar a ojo → horas quemadas en no-compradores.
9. CRM vacío o desactualizado.
10. Cotizaciones / propuestas a mano cada vez.
11. Sin nurturing → el lead frío se pierde para siempre.
12. Pipeline en la cabeza del comercial, no en un sistema.

**Clientes / soporte**
13. Las mismas preguntas respondidas mil veces a mano.
14. Tickets perdidos entre email y WhatsApp.
15. Cero post-venta → ni recompra ni referidos.
16. Onboarding de cliente distinto y caótico cada vez.

**Operación / admin**
17. Copiar datos de una herramienta a otra, horas/semana.
18. Aprobaciones internas perdidas en chats.
19. Agendar reuniones con ida y vuelta de emails.
20. Contratos / documentos rellenados a mano.
21. Tareas que dependen de "que alguien se acuerde".

**Finanzas**
22. Facturación manual.
23. Recordatorios de cobro que nadie manda → mora.
24. Conciliación bancaria a mano.
25. Recibos / gastos perseguidos a fin de mes.
26. Sin visibilidad de caja en tiempo real.

**Datos**
27. Datos en silos que no se hablan.
28. Decidir a ojo porque el dato llega tarde.
29. Dashboards que nadie actualiza.
30. Cruzar Excels a mano.

**Personas / RR.HH.**
31. Onboarding de empleado manual.
32. Vacaciones / permisos por email.
33. Horarios / nóminas en hojas frágiles.

**Inventario / logística**
34. Stock en una hoja que acaba petando.
35. Pedidos procesados a mano.
36. Sin alertas de reposición → roturas de stock.

**Web / digital**
37. Web lenta / frágil / alquilada.
38. Formularios que se pierden.
39. Landings que tardan semanas y cuestan un riñón.

*(40+ y siguen saliendo. The list is a living catalog.)*

## Diagnostic logic (replaces the slider)

For the bleed the prospect picks (one or a few), two follow-ups decide fit and
build desire:

1. **"¿Qué te sangra más?"** → pick from the menu (+ "otra cosa / cuéntamelo").
2. **"¿Ya tienes algo que lo resuelva?"** → `Lo hago a mano` · `Una herramienta a medias` · `Sí, resuelto`
   - *a mano* / *a medias* → **Stack opportunity** (the hole we fill).
   - *resuelto* → not a fit for that bleed (honest).
3. **"¿Qué tamaño tiene?"** (scale/cost proxy: people affected, hours/week, or revenue at stake) → sizes the prize + feeds the rough cost number.

Plus the two hard gates from strategy:
- **Fundability** (budget) — can this become a five-figure build?
- **Foundation** (where data lives) — can we build on it?

## How a pain → solution (prescription, not audit)

Each bleed maps to a **buildable sub-development**, anchored to a receipt when one
exists:

| Bleed family | Buildable solution | Receipt (proof) |
|---|---|---|
| Manual prospecting / no follow-up / dead CRM | sales/outreach automation | **AGLAYA Outreach** (Bill Capital) |
| Hand-built reports / no attribution / data silos | data + reporting layer | **AGLAYA Pulse** (Massiva) |
| Slow/rented web / lost form leads | owned web system | **AGLAYA Web** (DJ Amapola, Elm St.) |
| Chaotic onboarding / approvals / billing / copy-paste ops | internal workflow system | **AGLAYA Kanban Desk** |
| Anything else | bespoke sub-build | "we've shipped 4 fronts; we assemble yours" |

The deliverable reflects this map back personalized: *your bleed → its cost →
the system that stops it → proof → the audit that proves the exact number.*
