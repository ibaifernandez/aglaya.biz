## 1. What the diagnostic IS (the product logic)

A free ~3-minute quiz. The prospect answers ~10 questions about their manual work.
At the end they get a **real $ number** for what that work costs them per year, a
per-area breakdown, and a clear next step. It is the **free top of a value ladder**:

```
Diagnostic quiz  →  Personalized report  →  ROI Audit (paid)  →  The Stack (build)
   ATTENTION          INTEREST + DESIRE       DESIRE→CONVICTION     ACTION (5–6 figures)
   (free, hook)       (the number, the bleed) (exact number+plan)   (the real sale)
```

**The real sale is The Stack** — a bespoke automation build (tens of thousands). The
ROI Audit is the *paid door* to it (its fee credits 100% against the build). The
diagnostic is the *free door* to the audit. This is deliberate AIDA.

**Why this exists (demand-first):** search demand for "automation agency" is real in
**US/English** (BPA/workflow/RPA "services", low competition, CPC $9–55 — see
`docs/roi-diagnostic/06-keyword-volumes.md`). Spanish search is ~0 → for LatAm/Spain
the play is **demand-generation on RRSS**, not search. The site already speaks EN, so
the US/English play needs no new language, only ad targeting.

**The wedge (voice-of-customer, doc 07):** not "save time" — **"stop babysitting your
Zapier Frankenstein."** Lead with *fragility + mental overhead*, not software. The real
competitor is the patchwork the owner half-built and now maintains.

## 2. The flow (10 questions, current v2)

One question per screen, Typeform-style. Progress bar. **Email gate is at the END**
(after all questions, right before the number) — we moved it there because asking early
felt like an email grab, off-brand for an honesty-first product.

1. **(multi-select) Which areas bleed you?** — pick all (reports / leads / invoices / copy-paste / admin / scattered data)
2. **Which one hurts most?** (dynamic — only the selected areas shown; auto-skipped if only one)
3. How many people touch this work weekly?
4. Hours/week each?
5. What runs most of it today? (nothing / spreadsheets / off-the-shelf tool / a patchwork I babysit)
6. **When you get slammed, how often does something break or slip?** (fragility)
7. Team size?
8. Monthly tool spend?
9. **What have you already tried?** (nothing / hired someone / built a Zapier / bought a tool)
10. **Volume of the worst area** (units adapt per area — invoices/mo, leads/mo, reports/mo, hand-offs/wk, etc.)

→ **email gate** → computing → **report**.

**Design decisions locked (with the founder):**
- **Multi-select first** — richer signal (which areas, plural) + drives a per-area calc.
- **No repeated per-area battery** — that bored ("aburre a las ovejas"). Depth comes from *varied* questions asked once, not a loop per pain.
- **No revenue/billing question** — it reads as "sizing me up for a quote" and kills trust. Instead the "hits harder" stat is a **headcount/hours equivalence** derived from the answers ("≈ N full-time people producing nothing"). No money asked.
- **Volume is narrative color only**, never summed into the headline (its per-unit cost overlaps labor → would double-count).

## 3. The engine (how the number is computed)

Deterministic, no LLM. Traced to real data (doc 08: BLS loaded labor rates × 1.43, SaaS list prices, benchmarks). Files in `src/lib/diagnostic/`:

- **`costing.ts`** — `LOADED_RATE` per pain (role doing the work), midpoint buckets, `blendedRate()` (avg of selected areas' rates, **worst weighted ×2**), `computeLaborBleed()` (people × hours × 52 × blended rate → **≈ midpoint + ±40% band**), `computeSplits()` (per-area $ split, ordered desc = priority), `computeEquivalent()` (hours/yr + FTE).
- **`engine.ts`** — `computeDiagnostic(answers)` → full report; `computeTier()` (gates: scale + fundability + bleed size → qualified / borderline / not_yet); `tierToIcpStatus()` maps to the contact-funnel routing vocab.
- **`types.ts`** — all shared types.
- **`copy.ts`** — trilingual copy (EN/ES/PT), plain/human voice.

**Honesty rule (brand-critical):** the free report shows a **range** with visible
assumptions; the **exact** figure is the paid audit. The headline is a single ≈ number
(a raw bucket-edge range compounded to absurd widths like `$144K–$1.1M` and read as a
scam — so: point estimate + tight band).

**The report shows:** headline ≈ + band · equivalence ("≈ N FTE producing nothing") ·
"where it goes" per-area split · priority order · worst-area volume line · the blended
math · fragility line (from Q6) · prescription for the worst area, **sharpened by what
they already tried** (Q9 — e.g. "you built a Zapier you now babysit…") · tier CTA +
guarantee ("Honesty Clause") + scarcity.
