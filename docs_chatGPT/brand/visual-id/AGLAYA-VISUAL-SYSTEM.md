# AGLAYA VISUAL SYSTEM

> Documento maestro de identidad verbal-visual.
> Define nombre, subconcepto, taglines, postura de idioma y sistema visual base de AGLAYA.
>
> Este documento no cubre posicionamiento, ICP ni arquitectura comercial. Eso vive en `docs/brand/dna/BRAND-FOUNDATION.md`.

---

## 1. Nombre de Marca

### AGLAYA

El nombre se mantiene.

Tiene historia, reconocimiento y equity acumulado. En mitología griega, Aglaya es una de las tres Gracias: la que representa el brillo, la gloria y la excelencia.

No es un recurso ornamental. Es identidad.

---

## 2. Subconcepto de Marca

### Agenc·IA / AI·gency

Este es el subconcepto que expresa el posicionamiento central de AGLAYA.

- En español: `Agenc·IA` / `La Agenc·IA Incómoda`
- En inglés: `AI·gency` / `The Uncomfortable AI·gency`

### El punto `·`

El punto medio no es decorativo.

Su función conceptual es separar y unir al mismo tiempo:

- técnica y humanidad
- máquina y criterio
- sistema y verdad

Debe tratarse como un rasgo distintivo del sistema verbal de marca.

## 4. Postura de Idioma

El inglés es el idioma primario para alcance comercial.

El español se usa cuando el cliente, el canal o el contexto lo requieran estratégicamente.

La elección de idioma no comunica presupuesto. Comunica audiencia.

## 5. Sistema Cromático

| Rol | Valor | Nota |
|---|---|---|
| Color primario | `#e8003d` | Rojo AGLAYA |
| Fondo principal | `#080808` | Negro casi puro |
| Superficie | `#111111` | Base para bloques y contenedores |
| Acento para texto pequeño | `#ff4d70` | Mejor legibilidad sobre fondo oscuro |

### Uso recomendado

- `#e8003d` para impacto, acento, llamada visual y presencia de marca.
- `#080808` como base dominante del sistema.
- `#111111` para capas, tarjetas, contenedores o separación de profundidad.
- `#ff4d70` para texto pequeño o elementos que requieran contraste superior.

---

## 6. Accesibilidad Cromática

`#e8003d` sobre `#080808` ofrece una relación de contraste aproximada de 4.33:1.

Esto es válido para:

- texto grande
- elementos decorativos
- acentos visuales

Para texto pequeño, usar `#ff4d70` sobre `#080808`.

## 7. Tipografía

| Función | Familia | Uso |
|---|---|---|
| Display | Outfit 900 | Impacto, titulares, piezas de presencia |
| Texto de cuerpo | Inter | Lectura, interfaz, sistema, claridad |

### Principio tipográfico

El sistema debe comunicar precisión tecnológica con tensión editorial.

### Tratamiento

- UPPERCASE en labels o microcopys estructurales
- tracking amplio en etiquetas
- contraste claro entre bloque display y bloque de lectura

---

## 8. Dirección Visual

### Estilo general

Oscuro, tecnológico y minimalista.

### Tono fotográfico

Nada de stock genérico.

La imagen debe sentirse:

- real
- cruda
- propia
- con intención editorial, no corporativa

### Movimiento y animación

El sistema puede usar recursos como:

- entradas por palabras
- scanlines
- cursor glow

Las animaciones no deben parecer decorativas. Deben reforzar sensación de sistema, precisión y pulso.

---

## 9. Principios de Identidad Visual

1. **Oscuridad con intención**  
   El negro no comunica lujo vacío; comunica foco, tensión y claridad quirúrgica.

2. **Rojo como firma, no como ruido**  
   El rojo AGLAYA debe reservarse para marcar presencia, decisión y energía de marca.

3. **Tecnología sin cliché**  
   La estética debe sentirse técnica, pero nunca genérica ni derivativa.

4. **Humanidad dentro del sistema**  
   La identidad visual no debe borrar la carga narrativa de la marca. Debe sostenerla.

5. **Minimalismo con carácter**  
   Reducir no significa esterilizar. La marca necesita tensión, no frialdad vacía.

---

## 10. Aplicación Verbal-Visual

Cuando aparezcan juntos nombre, subconcepto y tagline, la jerarquía recomendada es:

1. **AGLAYA**
2. subconcepto (`Agenc·IA` / `AI·gency`)
3. firma estratégica o promesa (`From narrative to delivery.` / `Making AI work so you don't have to.`)

No saturar una misma pieza con demasiadas fórmulas simultáneas.

---

## 11. Lo que este sistema no debe hacer

- parecer SaaS genérico
- parecer consultora corporativa tradicional
- abusar del rojo hasta convertirlo en ruido
- usar imágenes de stock sin tensión ni verdad
- estetizar la tecnología vaciándola de significado
- sonar futurista sin sustancia

---

## 12. Definición Final

La identidad visual de AGLAYA debe hacer visible la misma idea que sostiene toda la marca:

verdad, tensión, sistema y criterio.

No se trata de parecer innovadores.
Se trata de parecer inevitables.
